## 1. 架构设计

```mermaid
flowchart TD
    A["纯静态页面 (HTML/CSS/JS)"] --> B["数据层 (data/articles.json)"]
    A --> C["页面模板"]
    B --> D["文章列表"]
    B --> E["文章详情"]
    C --> F["首页"]
    C --> G["文章列表页"]
    C --> H["文章详情页"]
    C --> I["关于页面"]
```

## 2. 技术描述
- **前端**：纯 HTML5 + CSS3 + JavaScript（无需框架，方便维护）
- **构建工具**：无（纯静态，直接编辑文件）
- **后端**：无
- **数据存储**：JSON 文件（data/articles.json 存储所有文章数据）
- **部署方式**：可直接部署至 GitHub Pages、Netlify 或任何静态服务器

## 3. 路由定义
| 路径 | 用途 |
|------|------|
| / | 首页 |
| /articles.html | 文章列表页 |
| /article.html?id=xxx | 文章详情页 |
| /about.html | 关于页面 |
